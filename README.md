# Crime Record Management System

## 📌 Overview
The **Crime Record Management System** is a web-based application designed to facilitate law enforcement agencies in managing crime records efficiently. It allows administrators to handle crime categories, police stations, officers, and generate detailed reports.

## ✨ Features
- 🔐 **Admin Dashboard** to manage the system efficiently.
- 🏢 **Police Station Management** for adding and updating police stations.
- 👮 **Police Officer Management** to keep track of officers.
- 📂 **Crime Categorization** for better classification of cases.
- 📝 **Report Generation** based on different criteria.
- 🔄 **Password Management** for security.

## 🚀 Installation Guide
### Prerequisites
Ensure you have the following installed:
- **PHP** (>=7.4 recommended)
- **MySQL** (or any compatible database)
- **Apache/Nginx** server
- **Git** (for cloning the repository)

### Steps to Install
1. Clone the repository:
   ```sh
   git clone https://github.com/SumanSnaik/CrimeRecordManagementSystem.git
   ```
2. Move to the project directory:
   ```sh
   cd CrimeRecordManagementSystem
   ```
3. Configure your database:
   - Import the provided `database.sql` file into MySQL.
   - Update the database credentials in `config.php`.
4. Start your Apache/Nginx server and ensure PHP is running.
5. Access the system via `http://localhost/CrimeRecordManagementSystem/`.

## 📌 Usage Guide
- **Admin Login:** Access the dashboard using admin credentials.
- **Add Categories:** Define crime categories for better case classification.
- **Manage Police Stations:** Add, update, and remove stations.
- **Add Police Officers:** Assign officers to cases.
- **Generate Reports:** View crime reports based on date ranges.
